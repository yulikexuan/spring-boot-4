# Implementation Plan: Fast Persistence-Slice Tests for Beer and Customer

**Branch**: `003-persistence-slice-tests` | **Date**: 2026-05-16 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/003-persistence-slice-tests/spec.md`

## Summary

Add a `@DataJdbcTest` slice for `BeerRepository` and `CustomerRepository`, backed by Zonky embedded PostgreSQL (via `embedded-database-spring-test`), exercising every `ListCrudRepository` method called by the service layer today (`save`, `findAll`, `findById`, `deleteById`). The slice loads no servlet/MVC infrastructure, applies the production DDL (`schema_renew.sql`) per class via `@Sql`, and runs in the Surefire phase as plain `*RepositoryTest.java`. No production code changes.

## Technical Context

**Language/Version**: Java 25 (parent `<java.version>25</java.version>`)
**Primary Dependencies**: Spring Boot 4.0.6, Spring Framework 7, Spring Data JDBC, JUnit Jupiter 6, AssertJ, Mockito (already on classpath via `spring-boot-starter-data-jdbc-test`)
**Storage**: PostgreSQL — production runs `localhost:54316`; tests use Zonky embedded PostgreSQL (`io.zonky.test:embedded-database-spring-test`) launched in-process per test class
**Testing**: Surefire (`*RepositoryTest.java`), `@DataJdbcTest` + `@AutoConfigureEmbeddedDatabase(provider = EMBEDDED)` + `@Sql("classpath:schema_renew.sql")` (constant renamed from `ZONKY` — same backend)
**Target Platform**: JVM 25 on Windows / Linux (Zonky pulls platform-specific binaries via Maven)
**Project Type**: Single module (`rest-mvc`) inside the multi-module reactor
**Performance Goals**: Whole suite (Beer + Customer ≈ 12 tests) finishes well under the time `@SpringBootTest` takes to print its banner (qualitative — SC-002). First-launch cost (binary extraction) ≤ ~5 s; subsequent classes reuse the cached binary.
**Constraints**: No external Postgres required; no `DATASOURCE_PASSWORD`; no controller / service / bootstrap-data collaborators loaded; DDL not redefined inside the test — `schema_renew.sql` is canonical; no assertion on `version` columns; existing controller-slice and service-unit tests untouched.
**Scale/Scope**: Two repositories, four methods each in scope, 12 tests minimum (per SC-003 matrix). Adds 1 test-scope dependency to `rest-mvc/pom.xml`; no changes to other modules.

## Implementation Outline (informational; binding plan is `tasks.md`)

1. **pom.xml** — add `io.zonky.test:embedded-database-spring-test` (test scope; version pinned in `research.md`).
2. **src/test/resources/application.yml** — set `spring.sql.init.mode: never` so Spring Boot's auto SQL init does **not** try to apply the production `schema.sql` (TRUNCATE/VACUUM) against an empty Zonky instance. Banner-off line stays.
3. **BeerRepositoryTest.java** — `@DataJdbcTest` + `@AutoConfigureEmbeddedDatabase(provider = EMBEDDED)` + `@Sql("classpath:schema_renew.sql")` + `@DisplayName` / `ReplaceUnderscores`. 6 tests (per SC-003 matrix + the round-trip + UUID-default cases from spec US1 / US2).
4. **CustomerRepositoryTest.java** — same shape, 6 tests.
5. Run `mvn test -pl rest-mvc -Dtest='BeerRepositoryTest,CustomerRepositoryTest'`; confirm green; confirm IT suite untouched.

See `research.md` for the rationale on each decision and `quickstart.md` for the developer-facing runbook.
